# Gentex PLACE v1 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a verified, immutable Gentex PLACE `v1.0.0` GitHub release that HACS installs from the tested ZIP while protected `main` blocks unreviewed or unvalidated changes.

**Architecture:** Pure Python helpers decide version changes, build deterministic archives, and construct branch-protection requests. A two-job GitHub Actions workflow keeps ordinary merges read-only and grants `contents: write` only to a release publisher after a valid version increase. The publisher creates a draft, downloads and checks its own assets, then makes the release public.

**Tech Stack:** Python 3.14.2, uv, pytest, Pillow 12.3.0, POSIX shell, SVG/PNG, GitHub Actions, GitHub CLI, GitHub REST API, Home Assistant 2026.8.1, HACS.

**Estimated change size:** 650–800 changed lines, mostly tests, release helpers, workflow policy, and docs, plus two tracked PNG assets.

- [ ] **Step 3: Implement the pure detector**

Use a frozen dataclass and a strict full-match expression. The decision core must be:

```python
_STABLE_VERSION = re.compile(r"(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)\Z")


@dataclass(frozen=True)
class ReleaseDecision:
    previous: str
    current: str
    required: bool


def parse_version(value: str) -> tuple[int, int, int]:
    match = _STABLE_VERSION.fullmatch(value)
    if match is None:
        raise ValueError(f"not a stable semantic version: {value!r}")
    return tuple(int(part) for part in match.groups())


def decide_release(
    previous_project: str,
    previous_manifest: str,
    current_project: str,
    current_manifest: str,
) -> ReleaseDecision:
    if previous_project != previous_manifest:
        raise ValueError("previous project and manifest versions differ")
    if current_project != current_manifest:
        raise ValueError("current project and manifest versions differ")
    previous = parse_version(previous_project)
    current = parse_version(current_project)
    if current < previous:
        raise ValueError("current version must not decrease")
    return ReleaseDecision(
        previous=previous_project,
        current=current_project,
        required=current > previous,
    )
```

Read both metadata files from a commit with `subprocess.run(["git", "show", f"{commit}:pyproject.toml"], cwd=root, shell=False, check=True, capture_output=True, text=True)` and the matching `manifest.json` object path. Translate missing commits, files, invalid TOML, invalid JSON, and missing version keys to a sanitized `ValueError(f"cannot read release metadata for {commit}")` with no raw subprocess output.

The CLI takes positional `before` and `after` SHAs plus optional `--github-output PATH` and `--require-release`. It prints a JSON object locally. `--require-release` raises a parser error unless the decision requests a release. When `--github-output` is present, append exactly:

```text

version=X.Y.Z
```

- [ ] **Step 3: Implement the two-job workflow**

Write `.github/workflows/release.yml` with this structure and exact authority boundary:

```yaml
name: Release

on:
  push:
    branches:
      - main

permissions:
  contents: read

concurrency:
  group: release-${{ github.ref }}
  cancel-in-progress: false

jobs:
  detect:
    runs-on: ubuntu-latest
    outputs:
      release_required: ${{ steps.version.outputs.release_required }}
      version: ${{ steps.version.outputs.version }}
    steps:
      - uses: actions/checkout@9c091bb21b7c1c1d1991bb908d89e4e9dddfe3e0
        with:
          fetch-depth: 0
          persist-credentials: false
      - uses: astral-sh/setup-uv@ae62891fec2bb8e7d6c99fc78c9fec3a63790f8d
      - run: uv python install 3.14.2
      - name: Detect version change
        id: version
        env:
          BEFORE_SHA: ${{ github.event.before }}
          AFTER_SHA: ${{ github.sha }}
        run: uv run python scripts/check_release.py "$BEFORE_SHA" "$AFTER_SHA" --github-output "$GITHUB_OUTPUT"
      - name: Refuse an existing tag or release
        if: steps.version.outputs.release_required == 'true'
        env:
          GH_TOKEN: ${{ github.token }}
          RELEASE_VERSION: ${{ steps.version.outputs.version }}
        run: scripts/check_release_absent "$RELEASE_VERSION"

  publish:
    needs: detect
    if: needs.detect.outputs.release_required == 'true'
    permissions:
      contents: write
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@9c091bb21b7c1c1d1991bb908d89e4e9dddfe3e0
        with:
          fetch-depth: 0
          persist-credentials: false
      - uses: astral-sh/setup-uv@ae62891fec2bb8e7d6c99fc78c9fec3a63790f8d
      - run: uv python install 3.14.2
      - run: scripts/check
      - name: Recheck release decision
        env:
          BEFORE_SHA: ${{ github.event.before }}
          AFTER_SHA: ${{ github.sha }}
        run: uv run python scripts/check_release.py "$BEFORE_SHA" "$AFTER_SHA" --require-release
      - name: Refuse a raced tag or release
        env:
          GH_TOKEN: ${{ github.token }}
          RELEASE_VERSION: ${{ needs.detect.outputs.version }}
        run: scripts/check_release_absent "$RELEASE_VERSION"
      - name: Build release assets
        run: uv run python scripts/build_release.py --output dist/gentex_place.zip
      - name: Create draft release
        env:
```
