# Gentex PLACE v1.0.1

## Why this patch exists

This metadata-only patch gives HACS a version newer than the test candidate so
existing `v1.0.0` installations can detect the update.
Integration behavior and dependency pins are unchanged.

## Upgrade with HACS

1. Back up Home Assistant and keep a downloaded copy on another device.
2. In HACS, find **Gentex PLACE**, open its three-dot menu, and choose
   **Redownload**.
3. Under **Need a different version?**, select `v1.0.1`, then choose
   **Download**.
4. Restart Home Assistant.

`v1.0.0` remains published for rollback. If this patch fails, use HACS
**Redownload** to select `v1.0.0`, download it, and restart Home Assistant.

## Verification

After the restart, confirm that Gentex PLACE loads and that its account and device
entities continue to update.

## Assets and dependencies

The release provides deterministic `gentex_place.zip` and
`gentex_place.zip.sha256` assets. It keeps the existing dependency pins and makes
no PyPI publication.
