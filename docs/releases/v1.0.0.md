# Gentex PLACE v1.0.0

Gentex PLACE is a read-only Home Assistant custom integration for monitoring the
PLACE devices in your account. It requests reported shadows and receives cloud-push
updates. It has no controls, services, commands, or desired-state writes.

## Included

- PLACE device discovery with cloud-push state updates and a fixed five-minute
  health refresh
- safety alarms, status fields, environmental telemetry, and device diagnostics
- password and MFA setup, reauthentication, and multiple-account support
- an original Home Shield icon released under this repository's MIT License

## Install with HACS

This repository is not in the HACS default store. Add it as a custom repository:

1. In HACS, open the three-dot menu and choose **Custom repositories**.
2. Add `https://github.com/harperreed/gentex-places-ha` with the type
   **Integration**.
3. On the **Gentex PLACE** entry, open the three-dot menu and choose
   **Download**.
4. Under **Need a different version?**, select `v1.0.0`, then choose
   **Download**.
5. Restart Home Assistant, then add **Gentex PLACE** from
   **Settings > Devices & services**.

## Upgrade with HACS

1. Go to **Settings > System > Backups**. In the lower-right corner, choose
   **Backup now**, then **Manual backup**.
2. Include the `config` folder, name the backup, and choose its location.
3. Download the backup emergency kit and store it safely, then select
   **Create backup**.
4. Select **Show all backups**. Select the new backup, open its three-dot menu, and
   choose **Download backup**. Keep the copy on another device.
5. In HACS, find **Gentex PLACE**. On its entry, open the three-dot menu and choose
   **Redownload**.
6. Under **Need a different version?**, select `v1.0.0`, then choose
   **Download**.
7. Restart Home Assistant and confirm that the account reconnects and device state
   updates.

These steps follow the official [Home Assistant backup instructions](https://www.home-assistant.io/common-tasks/general/#backups)
and [HACS repository update instructions](https://hacs.xyz/docs/use/update/).
The `config` backup contains the installed custom integration and Home Assistant's
stored config entries.

## Rollback

`v1.0.0` is the first release, so HACS has no earlier Gentex PLACE release to
select. If the upgrade fails, do not delete the integration or its config entry:

1. Preserve sanitized logs and the failed downloaded asset.
2. Go to **Settings > System > Backups**, choose **Show all backups**, and select
   the manual backup made before the upgrade.
3. Select the `config` folder and choose **Restore**. Home Assistant restores the
   pre-upgrade files and stored config entries, then restarts.
4. Sign in and confirm that the existing Gentex PLACE config entries reconnect.

The off-device **Download backup** copy remains available for wider Home Assistant
recovery. For later releases, HACS **Redownload** may offer an earlier published
version under **Need a different version?**.

A fix will use a higher patch release; published tags and assets stay unchanged.

## Release assets and dependency

The release provides deterministic `gentex_place.zip` and
`gentex_place.zip.sha256` assets. The integration installs its public PLACE SDK
dependency from Git commit
`d92f07ecc9b7e66162d60d4a66cc07366543b631`.

This is not a Home Assistant Core integration and does not publish the SDK to PyPI.
